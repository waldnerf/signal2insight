# AgenticRepair: Multi-Faceted Program Context Engineering for Agentic Vulnerability Repair

arXiv: [2607.29422](https://arxiv.org/pdf/2607.29422v1) &middot; Published 2026-07-31 &middot; Recommendation: **Review fully** (score 19/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## Key Highlights

- 73% success rate on 300 real-world vulnerability instances, beating the strongest baseline by 29%.
- Patches verified by sanitizers rather than self-reported as successful, so the number reflects fixes that actually hold.
- An ablation shows the three context types are complementary -- removing any one degrades the result, so this is not one trick doing the work.
- The gain comes from engineering the context, not from a bigger or better base model.

## Why It Matters for Enterprise AI

Patch backlog and mean-time-to-remediate are numbers security leaders already report upward, so an automated repair rate this high on real vulnerabilities changes a resourcing conversation rather than just a technical one. The more transferable lesson sits underneath the security framing: the performance came from deliberately assembling the context a human expert would have gathered, rather than from a stronger model. That is a design principle for any agent deployment where results have plateaued -- the question to ask is what context your expert gathers before acting, and whether the agent has it.

## Business Applications

- Evaluate agentic vulnerability repair against your own backlog with verified rather than self-reported fixes, and measure the effect on mean-time-to-remediate.
- Apply the context-engineering principle to underperforming agent deployments elsewhere: enumerate what your experts gather before acting, and check whether the agent receives it.
- Require sanitizer or test-based verification of any automated patch before it reaches a human reviewer, so the review queue contains only candidate fixes that hold.
- Treat the three context facets as a checklist when scoping any code-understanding agent, not just security ones.
