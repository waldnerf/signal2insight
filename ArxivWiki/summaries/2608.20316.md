# Pandora's AI Model Routing Box: Efficient Allocation with Costly Value Estimation

## High-Level Summary

When routing a request across multiple AI models or configurations to balance quality against cost, you first need to estimate how well each option would perform -- and that estimation itself costs money. This paper formalizes that tradeoff as a classic 'Pandora's Box' search problem and derives a closed-form rule for when it's worth paying to refine your estimate versus just picking a model and moving on.

## Key Highlights

- Gives a principled, closed-form policy (not a heuristic) for when extra evaluation spend on model routing is worth it.
- Directly formalizes the AI-spend-management problem enterprises running multiple models already face: cheap-but-noisy estimators versus expensive-but-accurate ones.
- The centralized policy ('Pandora's AI Model Routing Box') gives a mechanical rule any AI platform team could implement in a routing layer.

## Why It Matters for Enterprise AI

As enterprises run more model options (in-house fine-tunes, multiple vendors, different inference-time settings), routing decisions directly drive AI spend -- this gives a principled way to decide how much you should spend just deciding which model to use, rather than guessing.

## Business Applications

- Implement the Pandora policy in an internal model router to cut wasted evaluation spend.
- Use the framework to justify (or challenge) investment in more accurate but expensive routing infrastructure.
- Benchmark current routing spend against the paper's value-of-information threshold to find waste.
