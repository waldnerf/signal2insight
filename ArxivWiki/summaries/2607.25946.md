# A Low-Cost Human-in-the-Loop Investigation of Toxicity on GitHub at Scale

arXiv: [2607.25946](https://arxiv.org/pdf/2607.25946v1) &middot; Published 2026-07-28 &middot; Recommendation: **Review fully** (score 19/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## High-Level Summary

A labelling method for content too subjective for an LLM alone and too voluminous for humans alone. One call to a small local model returns both a label and interpretable category scores; a lightweight classifier then uses those scores to flag only the conversations likely mislabelled, sending just those to a human. It beat confidence-based and multi-LLM-ensemble routing at low added cost, applied to over 124,000 GitHub conversations.

## Key Highlights

- The validator routes human attention by predicted error, which outperformed using the model's own confidence -- the standard approach -- as the routing signal.
- It also beat multi-LLM agreement, which is the expensive default: no second and third model call per item.
- A small local model does the labelling, so cost and data residency are both controlled; the human is spent only where it changes the label.
- Used at real scale to re-test earlier small-sample findings, confirming some and qualifying others, rather than only producing new claims.

## Why It Matters for Enterprise AI

Every evaluation, moderation, and data-labelling pipeline hits this wall: LLM-as-judge is cheap but unreliable on exactly the ambiguous cases that matter, and full human review does not scale. This gives a concrete third option and shows the two obvious alternatives -- trust model confidence, or poll several models -- are both worse per unit of human effort. The requirement that the labelling model emit interpretable category scores alongside its verdict is the load-bearing design choice, and it is a change you can make to an existing pipeline.

## Business Applications

- Replace blanket human QA of LLM labels with error-predicted routing, and reallocate the freed review capacity to the flagged subset.
- Have judge models emit structured category scores rather than a bare verdict, so a validator has features to work with.
- Drop multi-model ensembles used purely for label agreement, where a validator gets better results for one model call.
