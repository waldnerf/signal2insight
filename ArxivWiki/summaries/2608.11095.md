# Why Does CLAUDE.md Keep Growing? Catastrophic Remembering in Agentic Coding

arXiv: [2608.11095](https://arxiv.org/pdf/2608.11095v1) &middot; Published 2026-08-11 &middot; Recommendation: **Priority review** (score 22/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## High-Level Summary

Analyzing 247,694 instruction lifetimes across 1,867 repositories, this paper shows that agentic coding instruction files (CLAUDE.md, cursorrules, etc.) grow without bound because deleting an instruction whose rationale has been forgotten risks breaking something -- so teams only ever append. The fix that halts the growth is cheap: write the rationale down as a comment instead of leaving it implicit.

## Key Highlights

- Instruction files more than triple in size over their lifetime (+226%), gaining +4.9 net instructions every commit, and older instructions get progressively less likely to ever be deleted.
- Names the failure mode 'catastrophic remembering' -- the inverse of catastrophic forgetting: once an instruction's rationale is gone, deleting it safely costs exponential effort in the size of the file.
- The fix (writing rationale as a comment) is validated two ways: a 99.3% reduction in excess instructions in a controlled synthetic setting, and a +23.1% instruction-following gain in a real-world benchmark.

## Why It Matters for Enterprise AI

Every engineering org running Claude Code, Cursor, or a similar coding agent is accumulating exactly this kind of bloat today, silently degrading agent reliability as the instruction file grows -- and the fix is a one-line process change (comment your rationale), not a new tool or vendor purchase.

## Business Applications

- Add a lightweight review step: every new CLAUDE.md/cursorrules instruction gets a one-line 'why' comment before merge.
- Periodically audit instruction files for undocumented, unremovable-by-fear entries as a form of AI-tooling technical debt.
- Use the paper's framing to justify investment in agent-config hygiene tooling or linting.
