# Inducing Task Models from Computer-Use Traces

## High-Level Summary

As computer-use agents start doing real work, organizations need a way to know what those agents are actually doing and reuse that knowledge. This paper introduces Task Model Induction (TMI), a method that takes raw, unlabeled traces of screen activity and mouse/keyboard events and reconstructs structured, auditable task models -- disentangling multiple interleaved goals from a single messy trace.

## Key Highlights

- Unlike prior work, TMI does not assume a single known task per trace -- it discovers the latent tasks inside an unconstrained, multi-threaded stream of activity first.
- For each discovered task, it builds a hierarchical, structured model (not just a step-by-step summary), making the result auditable and reusable rather than a one-off log.
- Directly targets a governance gap opening up right now: as computer-use agents enter production, nobody has a systematic way to audit what they learned to do or why.

## Why It Matters for Enterprise AI

Agent governance and auditability is becoming a real operational requirement, not a nice-to-have, as computer-use agents start touching production systems -- this gives platform and compliance teams a concrete mechanism to extract an inspectable record of what an agent actually does.

## Business Applications

- Build an audit trail of what automation agents actually do in production, independent of vendor-supplied logs.
- Reuse induced task models to onboard new agents faster instead of re-discovering the same workflow from scratch.
- Feed induced task models into a compliance review before expanding agent permissions.
