# Break It Down, Pass It On: Cross-Task Skill Transfer in LLM Agents

arXiv: [2608.20274](https://arxiv.org/pdf/2608.20274v1) &middot; Published 2026-08-20 &middot; Recommendation: **Review fully** (score 19/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## High-Level Summary

AI agents that induce and reuse 'skills' from past tasks are supposed to get better with experience -- but this paper shows that how you induce those skills determines whether they help or actively hurt. Coarse, task-level skills mostly make the agent worse than having no memory at all; finer subtask-level skills, in a text (not code) format, are what actually improve performance.

## Key Highlights

- Task-level skill induction reduces agent performance below a no-memory baseline on average -- reusing 'experience' can be a net negative.
- Subtask-level skill induction raises performance above the no-memory baseline, and text-formatted skills transfer better than code-formatted ones.
- A controlled, systematic comparison across the two axes (task vs. subtask granularity, text vs. code format) that most existing agent-memory methods vary informally.

## Why It Matters for Enterprise AI

Any team building agent memory or skill-reuse today is making an implicit choice about induction granularity and format that this paper shows can determine whether memory helps or hurts -- a direct, low-cost design correction before shipping an agent memory feature.

## Business Applications

- Audit an existing agent-memory feature for task-level (rather than subtask-level) skill induction as a likely source of regressions.
- Default new agent-memory implementations to subtask-level, text-formatted skill induction based on this evidence.
- Use the no-memory baseline comparison as a required test before shipping any agent 'learns from experience' feature.
