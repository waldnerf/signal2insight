# ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction

arXiv: [2607.29677](https://arxiv.org/pdf/2607.29677v1) &middot; Published 2026-07-31 &middot; Recommendation: **Priority review** (score 19/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## Key Highlights

- Commercial vision-language models score well on short documents but truncate record lists on long ones -- they return a plausible-looking partial answer rather than failing visibly.
- Coding agents stay accurate on those same long documents but at substantially higher cost per run.
- Grounding is scored separately at both word and page level, so 'can you show me where this number came from' is measured rather than assumed.
- The benchmark is published by LlamaIndex and their own LlamaExtract product ranks first on all three metrics -- worth weighing when reading the leaderboard.

## Why It Matters for Enterprise AI

The truncation finding is an operational risk, not a leaderboard footnote. A model that silently returns 40 of 60 line items produces output that passes a spot check and fails an audit, and nothing in a typical accuracy dashboard would surface it. Any team running document extraction at volume should be testing completeness on long documents specifically, separately from field-level accuracy. Beyond that, this is the first comparison that puts cost next to accuracy in the same table, which turns a technical evaluation into a procurement instrument: the accurate option and the affordable option are different here, and that trade-off is currently being made without data.

## Business Applications

- Add a long-document completeness test to your extraction acceptance criteria -- count records returned against records present -- rather than relying on field-level accuracy alone.
- Use the accuracy-versus-cost pairing to decide where an expensive agent-based approach is justified and where a cheaper model is adequate, per document type rather than as one global vendor choice.
- Require source-level grounding as a contractual requirement for any extraction vendor in a regulated process, and verify it with the benchmark's word- and page-level measures.
- Re-run the comparison independently before trusting the published ranking, given the vendor authorship.
