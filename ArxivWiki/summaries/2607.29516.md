# From Code Review to Code Critique: Intent, Drift, and Spotlight for AI-Generated Diffs at Scale

arXiv: [2607.29516](https://arxiv.org/pdf/2607.29516v1) &middot; Published 2026-07-31 &middot; Recommendation: **Priority review** (score 21/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## Key Highlights

- Intent prediction reaches 0.86 F1 and 90.2% approval from the developers whose changes it describes.
- Drift detection -- how far the agent's output diverged from the stated intent -- reaches near-perfect agreement with human annotators (QWK 0.907).
- The spotlight ranking beats the baseline AI reviewer by 2.4x on quality estimation while using 5x fewer tokens.
- In live rollout, drift scores cut code misalignment by a further 5.76 points, and no defects have been attributed to self-reviewed diffs since launch.
- The review taxonomy is derived from 18,000 real code reviews rather than assumed.

## Why It Matters for Enterprise AI

The bottleneck in AI-assisted engineering has moved. It is no longer how fast code gets written, it is whether anyone can still meaningfully check it -- and review capacity does not scale by hiring, because the volume is now set by machines. This reframes the problem from reviewing everything superficially to directing limited human attention at the specific regions where the agent most likely diverged from what was asked. The 5x token reduction means the governance improvement is also cheaper to run than the tool it replaces, which removes the usual objection.

## Business Applications

- Measure review coverage as a ratio against agent output volume, and treat a falling ratio as a governance risk rather than a productivity win.
- Adopt intent-versus-output drift as a release gate for agent-generated changes, rather than reviewing diffs uniformly regardless of origin.
- Redirect senior reviewer time to spotlight-ranked regions and measure whether escaped-defect rate holds, before expanding agent-generated code volume further.
- Use the token-cost comparison to justify replacing an existing AI review tool rather than adding one.
