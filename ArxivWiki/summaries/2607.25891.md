# Messier: A High-Resolution Corpus for Cross-Benchmark Agent Evaluation

arXiv: [2607.25891](https://arxiv.org/pdf/2607.25891v1) &middot; Published 2026-07-28 &middot; Recommendation: **Review fully** (score 20/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## High-Level Summary

A single standardised corpus of 957,253 agent evaluation records spanning 30 benchmarks, 714 agents and 11,891 tasks, each labelled by model, scaffold, environment, verifier and scoring rule. Two findings stand out: capability is very uneven by task type — function calling is saturated, programming is improving fastest, enterprise workflows remain hardest — and rescoring shows that strict all-pass scoring can hide progress and change which agent ranks first.

## Key Highlights

- Enterprise workflows are the least mature category measured, which is where most deployment budget is being spent.
- Function calling is effectively solved, so vendor differentiation claims based on it carry little information.
- Strict all-pass aggregation in multi-verifier tasks can obscure real progress and reorder agent rankings — a leaderboard position may be an artifact of the scoring rule.
- Every record carries occupational and industry classification, making the corpus usable for workforce and role-level analysis rather than only model selection.

## Why It Matters for Enterprise AI

This gives a defensible basis for sequencing an agent portfolio: it says plainly which categories are mature and which are not, rather than leaving the decision to vendor benchmarks. The aggregation finding is a procurement warning with teeth — two vendors can swap places depending on how partial successes are counted, so 'top of the leaderboard' needs the scoring rule attached before it means anything. The occupational labelling also makes it a starting point for judging which roles are actually exposed.

## Business Applications

- Sequence agent investment by measured category maturity, deprioritising enterprise-workflow automation relative to coding until the gap narrows.
- Require the aggregation rule alongside any benchmark number in vendor evaluations, since rankings shift when partial credit is counted differently.
- Use the occupational and industry classifications as an input to role-exposure analysis instead of commissioning that work from scratch.
