# Reusing Past Repairs Through Hierarchical Trajectory Abstraction for Coding Agents

arXiv: [2607.29658](https://arxiv.org/pdf/2607.29658v1) &middot; Published 2026-07-31 &middot; Recommendation: **Priority review** (score 20/25)

_Pre-extraction: this paper has only been screened on its abstract, not read in full yet._

## Key Highlights

- 81.2% of issues fixed on the first attempt on SWE-bench Verified, versus a baseline agent without the accumulated plans.
- The stored plans transferred to a completely different agent built by another team, lifting its first-attempt fix rate from 75.8% to 81.0% with no code change to that agent.
- Storing raw transcripts of past runs performed substantially worse than storing them as layered plans -- the abstraction step, not the logging, is what creates the value.
- Mixing several levels of abstraction beat using any single level, so a flat 'library of fixes' is the wrong shape for this.

## Why It Matters for Enterprise AI

This is the difference between an agent deployment that gets cheaper every quarter and one that costs the same on ticket 10,000 as on ticket 1. Most enterprise agent rollouts today have no mechanism for retaining what the agent learned, so the same class of problem is re-solved from scratch indefinitely. The transferability result also changes a procurement calculation: if the accumulated repair knowledge lives outside the agent and still works when handed to a different vendor's agent, then that knowledge -- not the agent subscription -- is the asset worth investing in, and switching vendors stops being a reset to zero.

## Business Applications

- Require that any coding-agent pilot include a mechanism for retaining and reusing past repair trajectories, and measure fix rate over time rather than at a single point.
- Treat the accumulated repair-plan store as a company-owned asset in vendor negotiations, and insist it remain exportable rather than locked inside the agent vendor's platform.
- Run the vendor-portability test directly: take the plans generated under one agent and measure the lift when applied to a candidate replacement agent, as evidence for or against switching cost claims.
